# Engineer Calculator 🔧⚡

Профессиональный инженерный калькулятор с возможностью построения графиков математических функций. Современный интерфейс в техно-стиле с киберпанк элементами.

## ✨ Возможности

### Калькулятор
- ✅ Базовые арифметические операции (+, -, ×, ÷)
- ✅ Тригонометрические функции (sin, cos, tan)
- ✅ Логарифмы (log, ln)
- ✅ Степени и корни
- ✅ Математические константы (π, e)
- ✅ Работа в градусах (DEG) и радианах (RAD)
- ✅ История вычислений с возможностью повторного использования

### Графики
- 📊 Построение графиков любых математических функций
- 📊 Настройка диапазона отображения по оси X
- 📊 Интерактивные графики с плавной анимацией
- 📊 Поддержка сложных функций

### Дизайн
- 🎨 Современный техно-дизайн
- 🎨 Киберпанк стилистика с неоновыми акцентами
- 🎨 Адаптивная верстка для всех устройств
- 🎨 Плавные анимации и визуальные эффекты

## 🚀 Быстрый старт

Просто откройте файл `index.html` в любом современном браузере!

## 💻 Технологии

- **HTML5** - структура
- **CSS3** - стилизация и анимации
- **React 18** - интерактивность
- **Math.js** - математические вычисления
- **Chart.js** - построение графиков

## 📖 Примеры использования

### Калькулятор
```
sin(45)         → 0.7071067812
π * 2           → 6.283185307
log(100)        → 2
sqrt(16)        → 4
2^10            → 1024
```

### Графики
```
sin(x)          - синусоида
x^2             - парабола
log(x)          - логарифм
cos(x)*x        - затухающая косинусоида
exp(-x^2)       - гауссиана
```

## 🎯 Использование

1. **Калькулятор**: Вводите математические выражения кнопками или с клавиатуры
2. **Режимы**: Переключайте между градусами (DEG) и радианами (RAD)
3. **Графики**: Введите функцию в поле f(x) и настройте диапазон X
4. **История**: Кликните на любое вычисление из истории для повторного использования

```bash

# или просто перетащите index.html в браузер
```

## 📦 Деплой на GitHub Pages

1. Форкните репозиторий
2. Перейдите в Settings → Pages
3. Выберите ветку `main` и папку `/ (root)`
4. Сохраните настройки
5. Ваш сайт будет доступен по адресу: `https://yourusername.github.io/engineer-calculator/`

Подробная инструкция в файле [deployment-guide.md](deployment-guide.md)
